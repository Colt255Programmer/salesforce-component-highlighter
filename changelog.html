Changelog

1.1.0

Current Pending review

A reliability and performance release. No new surface, but most of the internals were rebuilt.

  • Fixed: highlighting now actually persists across navigation, record changes and console subtabs. Saved state was being written to a storage area the page-side script could not read back, so it silently reset every time.
  • Fixed: the page is no longer blocked. Highlight overlays used to sit on top of components and swallow clicks, making every highlighted component unusable. Overlays are now a pass-through layer.
  • Fixed: Aura highlighting no longer modifies the page. It previously wrote inline styles into Salesforce's own elements and injected label nodes as their children, which could disturb Aura's rendering. Aura now uses the same external overlay approach as LWC.
  • Fixed: keyboard shortcuts. The Aura shortcut was listed as one key combination but listened for another, and the LWC shortcut was handled twice, so it could cancel itself out. Shortcuts now have one owner, and hover-only labels and snapshot export got their own entries.
  • Fixed: right-click menu actions could fail to reach the page.
  • Fixed: every popup toggle sent its command twice.
  • Fixed: Aura components written as c:myComponent were not being detected.
  • Much lower CPU use. The extension used to reposition every overlay on every single animation frame — around 60 times a second, forever, even on a page where nothing was moving. Position updates are now driven by scroll, resize and DOM changes, so an idle tab stays idle. Four overlapping DOM observers and a repeating background timer were collapsed into one.
  • Faster Aura detection on large pages: the old scan re-walked the whole page once per candidate component.
  • Narrower permissions. Two overly broad patterns meant Chrome had to warn that the extension could read data on all websites. It now requests Salesforce domains only; custom Experience Cloud domains can be granted individually. Setup and enhanced-domain hosts were added.
  • Rebuilt popup, and the version number shown in it is now read from the extension itself.
  • Renamed to Salesforce Component Highlighter — LWC & Aura, so the listing is findable by the terms people actually search. Same extension, same developer, nothing to reinstall.
  • New icon. The wordmark now reads “Salesforce Component Highlighter”, and the toolbar icon is the highlighter mark on its own — the old one tried to fit two lines of text into 16 pixels, which no icon can survive.

1.0.0

Initial release 16 November 2025
  • Highlight custom Lightning Web Components and Aura components on Salesforce pages.
  • Support for Lightning Experience, Experience Cloud and Classic, in production and sandbox.
  • Customizable highlight colors, hover labels, component counts.
  • Keyboard shortcuts and right-click menu actions.
  • JSON snapshot export of detected components.
