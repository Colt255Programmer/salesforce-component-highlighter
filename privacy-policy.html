Privacy Policy

Applies to the Chrome extension Salesforce Component Highlighter — LWC & Aura (extension ID ihcejjlpoaomlkklakoeohdmkbalhbel).
Last updated: 31 August 2026.

In short: this extension collects nothing, sends nothing, and has no server. It makes no network requests of any kind.

Data the extension collects

None. No personal information, no page content, no record data, no field values, no credentials, no session tokens, no browsing history, and no analytics or telemetry of any kind are collected, stored on any server, transmitted, sold or shared.

What the extension reads

To draw an outline around a component, the extension inspects the structure of the page you are viewing: element tag names, a small set of Aura identifying attributes, and each element's position and size on screen. This happens entirely inside your browser, in memory, while the page is open. Text you see on the page, values in fields, and record data are never read for any purpose.

What is saved, and where

Two things are saved, both using Chrome's own extension storage. Neither ever leaves your browser or your Google account:

  • Your chosen highlight colors — two color values, saved to Chrome's synced extension storage so they follow your Chrome profile across your own signed-in devices.
  • Whether each highlight layer is currently on or off — simple on/off values, saved to Chrome's session storage and discarded when you close the browser.

You can erase both at any time by removing the extension.

Snapshot exports

The snapshot feature builds a JSON file listing the component names detected on the current page, together with that page's URL, and saves it to your computer as an ordinary download. The file is generated locally and is never uploaded anywhere. Where it goes afterwards is entirely up to you.

Where the extension runs

The extension requests access to Salesforce domains only — force.com, salesforce.com, salesforce-setup.com, my.site.com, salesforce-experience.com and salesforce-sites.com. It does not run on any other website.

If your Experience Cloud site is served from a custom domain, you may optionally grant access to that one domain yourself from chrome://extensions. This is always your choice, applies only to the domain you name, and can be revoked the same way.

Third parties

There are none. The extension bundles no analytics, no advertising, no crash reporting, no external scripts and no third-party libraries. It contacts no server, including any server of the developer's.

Children

This is a developer tool and is not directed at children. Since it collects no data, it collects no data from children either.

Changes to this policy

If a future version of the extension ever changes what it reads or stores, this page will be updated before that version is published, and the change will be described in the changelog. Planned optional AI features are intended to run on your own device; if any option is ever added that would send data anywhere, it will be off by default and will state plainly what it sends before you turn it on.
